# 模型诊断手册（症状 → 判断依据 → 解决方案）

> **用法**：模型表现不对时，先在本手册找「现象」行，按「判断依据」确认，再按「药方」行动。
> 与 词汇字典.md（管词）、学习笔记.md（管事）并列，本手册管「病」。持续追加，标注出处 Day 号。

## 一、泛化健康度（学习曲线三态）

**判断顺序：先看训练线高低 → 再看两线缺口 → 最后看验证线走势。**

| 现象 | 判断依据 | 根因 | 药方 | 出处 |
| --- | --- | --- | --- | --- |
| 两条线都低，且很快贴合 | 训练 R²≈0，验证也低 | 高偏差 / 欠拟合（学不满，容量不足） | **加复杂度**：升 degree、换更强模型、减 λ；**加数据无用**（瓶颈是容量） | Day 025 |
| 训练高、验证低、缺口大 | 蓝≈1 但验证差 | 高方差 / 过拟合（背题） | **加数据 + 加正则**（λ↑ / C↓ / max_depth↓）；验证线随样本上爬 = 加数据在起效 | Day 025 |
| 两条线贴合且都高 | 缺口≈0 | 健康 | 直接用；下一步收集更多数据抬上限 | Day 026（0.9822 vs 0.9825） |

## 二、错误结构（混淆矩阵）

| 现象 | 判断依据 | 根因 | 药方 | 出处 |
| --- | --- | --- | --- | --- |
| accuracy 高，但少数类的错被总数掩盖 | 分类别统计错误数 | 类别不均衡（accuracy 被多数类主导） | 改盯 Recall / Precision；class_weight；分层抽样 | Day 026 |
| 假阴性（FN）代价最高：漏诊、漏报欺诈 | 错误的**业务后果**是否可逆 | 错误类型不对称，阈值 0.5 隐含"两类代价相等"假设 | **降阈值**：predict_proba + 自选阈值，无需重训；用误报换漏报 | Day 026 + 期望代价桥 |
| 假阳性（FP）代价最高：误杀正常邮件、误判正常人 | 同上，方向相反 | 同上 | **升阈值**：宁漏勿错杀 | 同上 |
| 只看总分不知道错在哪边 | 四格计数 | —— | 任何分类模型先出混淆矩阵再看总分 | Day 026 |

> 桥：决策 = 概率 × 错误代价。阈值由**代价矩阵**（业务决策）定，不是数学题。
> 例：恶性概率 0.3，漏报代价 100 / 误报代价 1 → 判恶性（0.3×100=30 ≫ 0.7×1=0.7）。

## 三、训练过程故障

| 现象 | 判断依据 | 根因 | 药方 | 出处 |
| --- | --- | --- | --- | --- |
| `ConvergenceWarning` | 求解器迭代到上限还没到谷底 | 特征量纲悬殊 或 max_iter 太小 | 先加 StandardScaler（树模型除外），再 max_iter↑ | Day 026 |
| 损失上下震荡不降 | 训练日志 | 学习率过大 | lr↓（÷10 试） | 吴恩达第1门 |
| 损失几乎不动 | 训练日志 | 学习率过小 或 模型容量不足 | lr↑（×10 试）；仍不动 → 换更强模型 | 同上 |
| 分数/损失出现 NaN | 输出异常 | 数值溢出（lr 太大）或输入含 inf | 检查 lr；检查数据清洗 | — |
| 测试分远高于 CV 分 | 两个数对比 | 大概率泄漏（测试信息进了训练） | 检查 scaler 是否在 Pipeline 内、测试集是否只碰一次 | Day 026 |

## 四、评估可信度检查清单（提交结论前过一遍）

| # | 检查项 | 不合格后果 |
| --- | --- | --- |
| 1 | 标准化等变换是否在 Pipeline 内（每折重新 fit） | 泄漏 → 分数虚高不自知 |
| 2 | 测试集是否只用了**一次**（最后一次） | 反复试 = 测试集退化成训练集 |
| 3 | 分类拆分是否加了 stratify | 某折类别偏斜 → 折间分数不可比 |
| 4 | CV 是否打乱（KFold(shuffle=True)） | 有序数据 → 验证集外推 → 天文负分 |
| 5 | 是否报 mean±std 而非单次分 | 单次分 = 随机变量，无可信度 |
| 6 | 指标是否匹配任务与代价（accuracy vs Recall） | 总分掩盖致命错误类型 |

## 五、模型选型对照

| 数据情形 | 首选 | 理由 | 出处 |
| --- | --- | --- | --- |
| 连续值预测、平滑关系、样本少 | 线性/逻辑回归 | 凸、可解释、可正则 | Day 025 |
| 表格数据（混合类型、异质特征） | 树集成：随机森林 / XGBoost / LightGBM | 自动处理非线性与交互，表格默认强基线 | Day 027 |
| 图像 / 文本 / 序列 | 神经网络（PyTorch，W6+） | 特征需自动学习 | 待学 |
| 要「为什么」的可解释报告 | 线性模型 / 单棵浅树 | 权重与分裂可直接讲人话 | — |

**要不要标准化**：模型依赖**跨特征线性组合**（w·x）→ 要；只做**单特征与阈值比较**（树）→ 不要。

## 六、调参旋钮速查（按模型）

| 模型 | 旋钮 | 方向含义 |
| --- | --- | --- |
| LogisticRegression | C | **C=1/λ**：C↓ = 强正则 = 抑制过拟合（反直觉，单独记） |
| LogisticRegression | max_iter | 迭代上限，防收敛警告 |
| DecisionTree | max_depth / min_samples_leaf / ccp_alpha | 树的"λ"：越小越不容易背题 |
| RandomForest | n_estimators / max_features | 树越多越稳；max_features 越小树间相关性越低（去方差） |
| GBDT / XGB / LGBM | n_estimators / learning_rate / max_depth | 学习率小配树多；max_depth 小防背题 |

## 快速诊断流程（一张流程）

```
模型表现不对
 ├─ 先画学习曲线
 │   ├─ 两线都低贴合 ──→ 加复杂度（容量瓶颈）
 │   ├─ 缺口大 ──→ 加数据 / 加正则（方差瓶颈）
 │   └─ 贴合且高 ──→ 看下一步
 ├─ 再看混淆矩阵
 │   ├─ FN 贵 ──→ 降阈值，盯 Recall
 │   └─ FP 贵 ──→ 升阈值
 └─ 还不行 → 加特征 / 换模型家族（线性 ↔ 树）
```
