# 学习笔记

30 周 LLM 应用工程师 × MLOps 双轨计划的每日学习笔记。

## 命名规则

`YYYY-MM-DD-dayNNN.md` —— 日期在前（按时间自然排序），天数为辅（对应 daily-plan.json 中的第 N 天）。

- day001 ~ day030：第 1 周 ~ 第 5 周（共同地基）
- day031 ~ day120：分叉期（周一/三 L 线，周二/四 M 线，周五按周次奇偶交替）
- day121 ~ day206：项目合流期

## 每日流程

1. **9:30** 企业微信收到当日计划推送（含学习材料链接）
2. 白天/晚上完成当日学习（在 WorkBuddy 会话中获得指导，自己动手）
3. **学习结束后**回到 WorkBuddy 会话说一声"整理今日笔记"，Buddy 会把当天学到的知识、命令、踩坑记进本目录
4. 自己 `git add / commit / push`，把笔记沉淀到 GitHub——既当复习，也练 git

## 笔记结构（每日固定模板）

- 今日目标与验收标准
- 核心知识点（讲原理，不抄文档）
- 今日亲手敲过的命令（速查表）
- 踩坑记录（报错 → 原因 → 解法，最有价值的部分）
- 验收结果
- 易忘点 / 自测问题
- 明日预告

> 笔记是写给自己未来复习用的：三天后回看，还能不能靠"自测问题"想起今天的东西？
