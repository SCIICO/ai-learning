# 学习笔记目录说明

## 结构

| 文件 | 用途 |
| --- | --- |
| **`学习笔记.md`** | **唯一笔记正文**。所有每日笔记按 `## Day NNN` 章节依次排列，顶部带目录表与踩坑总索引 |
| **`词汇字典.md`** | 专业术语字典：术语/中文释义/通俗解释/典型场景 + 知识点必要性图谱（按域分组，持续补录） |
| `2026-10-16-knowledge-map-day01-02.svg` | 知识点关系图（Day 001–002），正文中以相对链接引用 |
| `README.md` | 本说明文件 |

> 早期曾按 `YYYY-MM-DD-dayNNN.md` 分文件记录（Day 001–002），已合并进主文件 `学习笔记.md`，原文件可通过 git 历史查看。

## 每日更新方式

1. **9:30** 企业微信收到当日计划推送（含学习材料链接）
2. 白天/晚上完成当日学习（在 WorkBuddy 会话中获得指导，自己动手）
3. **学习结束后**回到 WorkBuddy 会话说一声「整理今日笔记」，Buddy 会：
   - 在 `学习笔记.md` 末尾追加一个新的 `## Day NNN · 主题` 章节
   - 同步在顶部**目录表**补一行，把新踩坑补进**踩坑总索引**
4. 自己 `git add / commit / push`，把笔记沉淀到 GitHub——既当复习，也练 git

## 每日章节固定模板

- 头部信息（日期 / 阶段 / 任务）
- 一、今日目标与验收标准
- 二、核心知识点（讲原理，不抄文档）
- 三、今日亲手敲过的命令（速查）
- 四、踩坑记录（现象 → 原因 → 解法，最有价值的部分）
- 五、验收结果
- 六、易忘点 / 自测问题
- 七、次日预告

> 复习方法：合上细节，只看「知识点关系图 + 踩坑总索引 + 自测问题」，讲不出来的部分回去翻对应章节。
